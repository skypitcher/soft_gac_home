# Newsreader

The homepage slogan uses the normal and italic Latin WOFF2 subsets of Newsreader, served locally. These variable fonts support optical sizing and the weight range 400–650 used by the page.

- Source: [Google Fonts](https://fonts.google.com/specimen/Newsreader)
- Upstream: [google/fonts — Newsreader](https://github.com/google/fonts/tree/main/ofl/newsreader)
- License: `OFL-Newsreader.txt` (SIL Open Font License 1.1)

Font files were obtained from the official Google Fonts stylesheet; no runtime request to Google Fonts is needed.
